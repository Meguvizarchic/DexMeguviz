# 有界静态 DEX 流输出 v1

`DexStreamExport.writeTo` 将单个快照来源 occurrence 的静态 DEX 字节按调用方指定的块大小（1–1048576 字节）复制到调用方提供的 `OutputStream`；`writeAll` 根据 SourceSet 展开的来源顺序分别输出到一一对应的流。输入为 APK 时输出解压后的 DEX，而不是原 APK。返回的长度仅代表成功调用输出流的字节数，不证明文件已持久化、APK签名、来源真实性或ClassLoader绑定。该接口不创建路径，也不自动 flush 或 close 流。

调用方必须指定正的单来源及总字节上限；writeAll 对全部来源数量和长度先检查后写，超限/流数量错误不会输出。重复的同一流对象会在写入前拒绝；不同流是否指向同一目的地由调用方确认。输出流或并发关闭快照导致中途失败时会抛异常，已经写出的数据不会回滚；调用方负责事务、命名、部分输出处理和目的地安全。输出流可能执行任意调用方代码：每次native读取仅在快照监视器内进行，调用输出流时不持锁，避免锁内执行外部代码；调用者须自行协调并发 close。缓冲为一个指定大小的 Java byte[]，不计入 native Engine 账本，也不代表RSS/速度优势。

这是独立的流式复用接口，不承诺与任何路径写入API同签名或同文件命名；不认证 loader/ART，不支持因此推断完整应用范围。
