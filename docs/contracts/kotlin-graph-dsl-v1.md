# Kotlin typed metadata graph builder

`GraphExpression` constructs v3 metadata scan/filter/label/union/distinct/group/join/semi-join expressions for seven `EntityRelation` roots. `GraphPredicate.from(EntityPredicate)` reuses the direct-entity writer; explicit `reflectionFlags`/`reflectionOwnerFlags` use `ReflectionFlags`, which are static reflection-model bits rather than raw DEX access flags. Boolean `all`/`any`/`not` preserve core semantics and Unknown; the builder never evaluates a predicate or determines completeness.

`GraphQuery` emits ASCII QueryIR JSON. A graph containing a reflection predicate explicitly declares both reflection capabilities, selecting v14 when accepted by the core; a graph without one uses the normal v3 metadata profile. Native compilation remains authoritative for predicate depth, JSON node counts, operator combinations and actual capabilities. The builder validates relation applicability, join families, labels, unsigned group bounds, duplicate roles, graph node count (128), graph depth (32) and 64 KiB JSON size. The bound on graph depth is not a promise that every nested predicate fits the native JSON depth budget.

`TypedGraphQueryExecution.execute` and `startJob` accept a single or multi-source snapshot and forward the generated JSON to the existing JNI graph bridge. Source scope stays incomplete. Job batches are provisional: consume to EOS, then check the final status; an output/decoding failure invalidates the stream. The JNI bridge accepts at most 4,096 results and 100,000,000 work units, even when the builder can represent larger limits; its query size, supported profiles and copy budgets also remain in force. No type for explicit source scope, graph sort/projection, use events, inheritance or arbitrary future operators is provided in this writer; use the documented JSON bridge where appropriate, and unsupported combinations are not silently downgraded.

Fixed Windows JVM and CLI tests cover static scan/filter, labels, union/distinct, join/semi-join, group, a mixed raw/reflection predicate, Unknown, Exists, asynchronous graph batches, limits and invalid relation/label/role forms. These are static samples, not full QueryIR, Android/ART, runtime reflection or ClassLoader proof. Kotlin standard library remains provided by the host.
