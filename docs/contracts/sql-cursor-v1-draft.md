# 内部严格提交与有界分页游标

`SqlSession::query_cursor_scoped` 只接受 `open_scoped` / `open_scoped_planned` 会话，沿用 `query_scoped` 的单语句只读、SQL 绑定、SQLite 残余、来源范围、工作和取消契约。整条语句在有界内存暂存区内完成 step、finalize 和取消检查后，才创建并提交独立 `SqlCommittedCursor`；任何错误、预算、取消或分配失败不产生游标。非空输出指针被拒绝，旧游标不替换。此入口不输出 provisional 批次，不提供磁盘 spool；超过现有最多 100,000 行、8 MiB 逻辑结果预算明确失败。

`query_cursor_scoped_bound` 采用与 `query_scoped_bound` 相同的有界位置参数列表，随后遵循相同的严格提交屏障和分页协议。绑定失败不会产生游标，也不会替换已有非空游标；调用期间参数及文本字节必须保持稳定。

需要逐行消费时，可显式使用独立的 [暂定行与终态协议](sql-provisional-v1-draft.md)；不能把它的回调当作已提交分页。

游标持有已复制并完成提交的行和原始 snapshot ID、来源范围及计数，不再引用会话或 DEX；关闭会话、释放快照后仍可读取。每个游标只代表一次已提交的 SQL 和 snapshot，不接受新的计划、排序、位置或 snapshot 输入，也不通过重执行做分页。SQL 无 `ORDER BY` 时页顺序仅是本次实际执行顺序，不能当作跨执行的稳定顺序或跨快照身份。调用者不得跨线程并发使用、移动或关闭同一游标；取消回调不得重入同一游标或会话。

范围会话可在首次有效游标尝试之前一次性调用 `configure_cursor_quota`，显式限制同一会话创建且仍保留结果的游标数（1–1024）和逻辑结果字节总量（1–1 GiB）；默认未配置，旧行为不变。每次创建先保留一个名额，超出数量返回 `SQLITE_BUSY`；完整查询成功后立即开始有效期计时，再计算实际保留行的逻辑字节并尝试计入总量，超出返回 `SQLITE_TOOBIG`，计量或分配期间已过期返回 `SQLITE_ABORT`。失败、取消、游标分配失败均归还已占名额且不交付游标。逻辑字节口径与分页相同：每行 8 字节加每列 16 字节及 TEXT UTF-8 字节，空结果仍占一个游标名额；它不包含快照标签、容器开销、临时查询、SQLite、已复制页面或 RSS。读取终页不会自动释放配额；显式 close、析构或在 `next` 中检测到过期才释放，过期不是后台自动回收。

`cursor_quota_stats` 可在范围会话打开期间读取限制与当前占用；未配置返回 `SQLITE_NOTFOUND` 且不改输出，关闭后返回 `SQLITE_MISUSE`。各计数通过原子值采样，不保证在不同游标并发释放时反映同一瞬间。游标可在会话关闭/析构后继续独立读取，持有共享配额对象直至释放；会话及同一游标的既有单线程规则不变。该配额不覆盖跨会话、不提供进程总内存上限，也不保证实时抢占或回收。

`next` 每次要求 1–4096 行、1–8 MiB 逻辑页预算，按原查询的每行 8 字节加每列 16 字节和 TEXT 码元的 UTF-8 字节数计费；该预算不含结果元数据、容器分配器开销、调用者已保留页或 RSS。页面先在私有对象中复制，完成后才更新输出和位置：页首行本身超额返回 `SQLITE_TOOBIG`，取消返回 `SQLITE_INTERRUPT`，分配失败返回 `SQLITE_NOMEM`，均不改变调用方输出或游标位置。页可由调用者在游标关闭后独立持有；多个页的累计内存由调用者负责。

成功页包含零起始 `first_row`、是否为最后一页、范围标签和原 snapshot ID；空结果产生一个零行终页。读取终页后，若游标尚未到期，下一次返回 `SQLITE_DONE`；若调用时已经到期，期限检查优先，返回 `SQLITE_ABORT` 并关闭，不伪装为 EOF。显式关闭或已经因到期关闭后返回 `SQLITE_MISUSE`。该 EOF 只表示本次已提交的结果读完，不意味着来源范围是全局完整。有效期为完成查询后开始计时的 1–600,000 毫秒，使用单调时钟，在 `next` 调用时及提交页前检查；内存仅在检查到期、显式 close 或析构时释放，不承诺后台定时释放或硬实时期限。

这是单线程桌面 C++ 内部草稿，并非公开 C ABI、CLI、Android、持久跨进程游标或完整 P3-03。固定测试覆盖分页与独立普通 SQLite 结果、跨 snapshot/不同查询隔离、语句错误/预算及已返回行后的取消、COUNT 和 NOT EXISTS 扫描分配失败、页复制失败及恢复、空结果和到期；COUNT / NOT EXISTS 的固定样本还在 native 使用点收集器内第六次取消检查处中断，验证严格结果不替换、游标不产生以及配额归还；模拟分配失败使用测试钩子，不证明真实系统 OOM。终页后到期采用测试钩子确定性设定期限，独立的其他样本使用真实单调时钟。以上均是限定主机证据，不证明所有错误路径或进程内存上限。
