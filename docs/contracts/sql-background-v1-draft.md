# 桌面后台 SQL 队列（内部实验候选）

该入口仅随默认关闭的桌面 SQLite 适配器构建，与现有单线程 JSON Lines CLI 相互独立，不是公开 C ABI、MCP 服务或进程间协议。后台 worker 自行创建、使用、关闭并析构唯一 SqlSession；同一实例内部 API 可由多个线程并发调用，析构必须由调用者独占。打开期间 snapshot 不能并发释放或关闭；会话建立后持有 Dataset，不需要原 snapshot 继续存活。借用来源及生命周期回调必须满足来源契约及实际 worker 线程的线程安全约束。

提交深拷贝 SQL 和参数，单项行数、字节、进度与参数上限沿用内部 SQL 接口；在锁内原子占用固定槽、输入逻辑字节及声明的结果预算。拒绝时不创建任务、不修改 id；相同字节多来源仍按原 occurrence 处理。worker 按接受 id 顺序执行尚未取消的任务。排队任务取消立即生成保留的 INTERRUPT 终态；运行中取消设置原子标志，在 SQL 的协作检查点观察，成功与取消以终态锁定先后决定。SQL 已先返回的错误保留优先级。终态只在完整 SQL 返回并 finalize 后发布；失败不带结果。`BackgroundStats.interrupted` 是所有 `SQLITE_INTERRUPT` 终态数，包括进度预算耗尽，不代表调用 cancel 或 shutdown 的次数。底层 profile 描述执行器自身，可能在执行成功后、发布之前收到取消而仍显示 SQLITE_OK；必须以外层 execution_status 为准。

每个成功提交的任务在 live 对象内保留终态至 acknowledge；读取终态返回独立深拷贝，读取分配失败不改变目标或丢弃终态。未完成任务读取返回 BUSY。确认后才释放槽和结果预留；重新读取已确认 id 返回 NOTFOUND。输入预算按 SQL 字节、每参数逻辑 32 字节及 TEXT 字节计量，结果预留按调用方声明的 max_bytes 累计，不覆盖实际容器容量、SQLite、输入临时拷贝、线程栈、调用方取得的终态副本或 RSS，不是全进程内存上限。

shutdown 关闭新任务准入；false 继续执行已有排队任务，true 将排队任务转为取消终态并请求运行任务协作取消。它不抹除未确认终态。close 在尚未 shutdown、存在任务或终态时返回 BUSY；空闲时由 worker 同线程关闭会话并 join，关闭错误保留 worker 以便重试。取消检查与关闭不保证墙钟时限。调用者必须显式读取、确认并 close；析构是放弃对象，强制请求取消并等待 worker，未确认终态随对象销毁而丢弃，禁止在析构期间并发调用。操作系统线程/互斥设施发生异常失效、进程崩溃、掉电和重启不保证恢复，SQLite close 失败时底层已有泄漏回退边界仍适用。

测试覆盖固定主机样本，并发申请、容量满、排队与运行取消、计算与提交间竞态、显式确认、限额、复制与 worker 的合成分配失败、close 模拟失败后重试及旧同步 CLI；注入故障不代表实际系统 OOM。worker 不提供真正的后台服务发现、持久任务、跨进程队列或生产接入，不证明完整 P3-04、Android/BIL、平台一致性与性能。
