# 静态注解匹配 v1（局部候选）

`AnnotationMatcher` 在已有 `AnnotationResult.Item` 上执行精确比较，不扫描 DEX，不改变核心 profile。`metadata` 比较完整 descriptor 和可见性；`scalar` 比较显式元素的确切 DEX 种类及整数、原始浮点位、布尔、null 或来源局部引用索引；`text` 通过调用者提供的解析器比较 STRING 或 TYPE 的 UTF-16 文本。引用索引只在结果同一来源中有意义，调用者必须将解析器绑定到 `AnnotationResult.sourceIndex` 及同一快照；该接口不认证调用者的绑定。

三种状态严格区分：已知满足为 MATCH，已知不满足为 NO_MATCH；元素未显式编码时为 UNKNOWN，因为可能存在默认值，解析器缺失或返回 null 也为 UNKNOWN。解析器异常、格式错误和预算耗尽向上传播，不将它们转为空结果。显式字段重复时报错。只按已有复制结果逐项匹配；不推断未读取的注解、运行时对象、默认值、跨来源引用等。

匹配器要求调用方为每次调用设置元素数上限和 `EncodedValue.Limits`，并在复制编码前验证字节上限；预算独立于原生读取预算和进程内存，调用者负责多次调用的总预算及解析器本身的限制。数组、嵌套注解不能作为匹配条件，显式要求这些类型会被拒绝；已有编码中遇到与标量条件不同的数组或嵌套类型，经过有界解码后可判定种类不匹配。引用索引比较不验证索引表或解析其目标；浮点按原始位比较，包括 NaN 负载与负零。

这是静态局部匹配构件，不覆盖注解默认值求解、嵌套/数组匹配、DexKit 全部匹配语义、ART 行为或性能证明。
