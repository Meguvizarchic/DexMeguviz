# Static class annotation reflection flags v20

`reflection_class_annotations_static` is an explicit opt-in QueryIR capability and requires `reflection_flags_static`. Its ID domain is `query:v20`; existing capability sets, IDs and metadata-open behavior remain unchanged. It is a source-local static model, not a claim about a class bound by an ART runtime or class loader. The v20 Android entry is synchronous; existing graph and job entry points retain their previous wire and supported profiles.

For a locally defined class, inspect that definition's class annotation directory and its class annotation set in the same DEX occurrence. For class definitions/type references, this applies to reflection `flags`; for member rows, it applies to reflection `owner_flags`. A missing local class remains Unknown; neither another input occurrence nor a referenced class supplies a definition. A checked class with no annotation directory, no class annotation set, or no system-visible `Ldalvik/annotation/InnerClass;` falls back to the existing class raw-flag projection only after the set has been scanned. A matching annotation's top-level `accessFlags` must be a signed DEX `VALUE_INT`; its width is sign extended. Unknown bits, conflicting visibility, missing/wrong type, or an already unknown raw class encoding remain Unknown. Malformed metadata is rejected by the existing metadata reader; re-reading also checks consumed boundaries and is subject to the query work limit and cancellation. Temporary traversal memory uses the query's memory resource.

A matched class flag observation emits C witness kind `DMG_WITNESS_CLASS_ANNOTATION_FLAGS` exposed through `dmg_result_get_class_annotation_flags_witness_v1`. `source_index` and `class_ordinal` are local identity; `source_kind` 0/1/2/3 denotes no directory, no class set, no matching system InnerClass, or an InnerClass int. The offsets refer to the original DEX occurrence, are zero when absent, and `encoded_flags` is meaningful for kind 3. `raw_flags` is the class definition's raw access flags and `projected_flags` is the modeled result. A non-matching predicate may carry an observation when it is used under boolean composition; `matched` remains the leaf truth value. Unknown is never converted into raw flags and has no successful observation witness.

`NativeEngine.Snapshot.queryClassAnnotationGraph` and `SourceSetSnapshot.queryClassAnnotationGraph` consume the versioned graph wire. `ClassAnnotationGraphQuery` and `ClassAnnotationGraphExecution` provide a Kotlin facade; Kotlin remains host-provided. `GraphResult.Witness.classAnnotationFlags` is null on old wires and unrelated witnesses. New Android code performs static checks only and does not establish Android load, R8, performance, device or BIL integration.

The reference mapping is limited to the following independently fixed AOSP revisions, which are not shown to form the same release: [libcore Class.getModifiers](https://android.googlesource.com/platform/libcore/+/f080dbcfd1b59b3e1a49b1f1aad90051a9787cdc/ojluni/src/main/java/java/lang/Class.java), [ART Class::GetInnerClassFlags](https://android.googlesource.com/platform/art/+/5a2301d897294ff4ee6de71f459dc2566dc3fa1a/runtime/mirror/class.cc), and [ART dex annotation reader](https://android.googlesource.com/platform/art/+/d33d318685ec4a1c9e7995c914c104ab6487513b/runtime/dex/dex_file_annotations.cc). Conservative Unknown cases are narrower than a claim of complete ART equivalence.
