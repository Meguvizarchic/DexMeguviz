# Android 静态注解读取 v1

`Annotations.collect` 和 Kotlin `AnnotationExecution.inspect` 同步读取单个来源中已定义的类、字段、方法或参数的静态 DEX 注解。调用方需明确指定目标及预算；SourceSet 入口需明确指定来源索引。方法参数索引属于该方法的显式参数序列。读取应安排在非 UI 线程。

成功结果包含来源及快照身份、目标索引、工作量、注解可见性、类型 descriptor、元素名称、类型和参数位、原始 DEX 偏移及编码。字符串保留 UTF-16 code units；`encodedAnnotation()` 和 `encodedValue()` 返回防御性副本，完整保留嵌套注解和数组等编码内容，不将其解释为空值。结果已复制，可以在快照关闭后使用。可另用 [EncodedValue](encoded-value-v1.md) 对元素原始值做有界类型化解码；其引用仅返回局部索引。

成功且数量为零表示所选来源中已定义目标没有静态注解；未定义或仅外部引用的目标由核心返回 Unsupported，非法索引及预算耗尽保留各自失败状态，不输出部分结果。错误不等同于零注解。读取和关闭同一 Java 快照通过对象监视器协调；JNI native 临时结果在每条路径释放。

结果身份描述静态来源及源集合中的出现位置，不认证运行时 ClassLoader、实际加载范围或调用方声明的作用域，也不构成完整 DEX 验证。不得据此推断运行时绑定或其他来源中的注解。

限制包含记录数、工作量、编码字节数及相对截止时间；传输采用额外 8 MiB 上限，文本长度及记录数另受上限约束。完整注解和元素编码在传输时均被复制，因此传输预算可能先于 native 编码字节预算耗尽；失败不返回部分结果。关闭快照不清除已复制的 Java 结果。
